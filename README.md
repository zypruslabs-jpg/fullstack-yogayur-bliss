# YogAyur Bliss — Wellness Website

Premium Ayurveda + Yoga + Holistic Wellness brand website.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber (3D Lotus)
- Framer Motion ready
- Lucide React icons

## Pages
- `/` — Home (Hero, About, Services, Programs, Why Us, Testimonials, FAQ, Contact)
- `/about` — About & Mission
- `/services` — All 8 services
- `/programs` — All 8 wellness programs
- `/blog` — Wellness knowledge hub
- `/contact` — Contact form + WhatsApp
- `/privacy-policy` — Privacy policy
- `/terms` — Terms & Conditions

## Quick Setup

```bash
npm install
npm run dev
```

## Before Deploying — Replace These:

1. **WhatsApp Number**: Search & replace `91XXXXXXXXXX` with your actual number (with country code, no + sign)
2. **Email**: Replace `info@yogayurbliss.com` with your actual email
3. **Formspree**: Replace `YOUR_FORM_ID` in ContactForm.tsx — get free ID at formspree.io
4. **Google Analytics**: Add your GA4 ID in layout.tsx
5. **Domain**: Update `yogayurbliss.com` in metadata, sitemap, robots

## Deploy to Vercel

1. Push to GitHub
2. Connect repo to Vercel (vercel.com)
3. Select Next.js framework
4. Deploy — live in 2 minutes!
